# 📎 Ressources officielles

[← Sommaire](../README.md)

Le cours est rédigé pour Java 21, avec la syntaxe classique main et sans fonctionnalités expérimentales. Les pages officielles peuvent aussi présenter des versions plus récentes : vérifie toujours la version d’une API avant de l’ajouter à ton projet.

| Besoin | Source |
| --- | --- |
| Tutoriels du langage | [Dev.java](https://dev.java/learn/) |
| Rechercher une classe et ses méthodes | [API Java SE 21](https://docs.oracle.com/en/java/javase/21/docs/api/) |
| Installer un JDK | [Eclipse Temurin](https://adoptium.net/temurin/releases/?version=21&os=windows) |
| Configurer VS Code | [Premiers pas Java](https://code.visualstudio.com/docs/java/java-tutorial) |
| Déboguer | [Débogueur Java dans VS Code](https://code.visualstudio.com/docs/java/java-debugging) |
| Organiser plusieurs fichiers | [Projets Java dans VS Code](https://code.visualstudio.com/docs/java/java-project) |
| Collections | [Collections Framework](https://dev.java/learn/api/collections-framework/) |
| Records | [Données immuables avec les records](https://dev.java/learn/records/) |
| Streams | [API Stream](https://dev.java/learn/api/streams/) |
| Dates | [API Date Time](https://dev.java/learn/date-time/) |
| Organiser les dépendances ensuite | [Maven : premiers pas](https://maven.apache.org/guides/getting-started/maven-in-five-minutes.html) |
| Approfondir les tests ensuite | [Guide utilisateur JUnit](https://docs.junit.org/current/user-guide/) |

Pour consulter une méthode, repère sa signature, son type de retour, ses paramètres et les exceptions documentées. Essaie ensuite un exemple minuscule dans ton propre fichier. Cette habitude sert davantage que de mémoriser toutes les méthodes de la bibliothèque.
