## Référence de présentation

Le projet s’inspire du [30 Days Of Python d’Asabeneh Yetayeh](https://github.com/Asabeneh/30-Days-Of-Python) : sommaire de trente journées, dossiers et fichiers numérotés, bannière commune, exemples, exercices par niveau et liens précédent / suivant. La page d’accueil comprend aussi le jour 01 pour retrouver cette organisation.

Ce parcours Java a été créé pour **NathanLeBgdefou**, avec assistance de ChatGPT/Codex. Les textes pédagogiques, exercices, programmes et visuels sont propres à ce dépôt. Le cours ne prétend pas être une édition officielle du projet d’Asabeneh ni une publication officielle de Java, de Microsoft ou de VS Code.

## Choix du contenu

Le programme vise les fondamentaux utiles aux études pour une personne ayant déjà un peu pratiqué Python : syntaxe, types, contrôle, méthodes, algorithmes, programmation objet, collections, erreurs, fichiers et tests. L’ordre adapte les notions au langage Java ; il ne transpose pas artificiellement les bibliothèques Python en trente équivalents Java.

Les exemples utilisent le JDK seul. Les tests automatiques du dépôt compilent les programmes et comparent leurs sorties à des résultats attendus. Les tests du carnet final vérifient ses règles et le stockage. Les détails de vérification figurent dans [VALIDATION.md](./VALIDATION.md).

## Visuels

Les bannières, badges et schémas sont des SVG locaux, lisibles sur GitHub sans dépendre d’un service d’images externe. La palette bleue, le bandeau sombre, les touches jaunes et les formes simples reprennent les repères visuels de la référence ; le dessin de tasse et les schémas ont été réalisés pour ce cours.
