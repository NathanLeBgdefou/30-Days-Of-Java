# 📖 Glossaire

[← Sommaire](../README.md)

| Mot | Explication simple |
| --- | --- |
| Argument | Valeur fournie lors d’un appel de méthode. |
| Attribut / champ | Donnée déclarée dans une classe ; un champ d’instance appartient à chaque objet. |
| Bytecode | Représentation compilée que la JVM peut exécuter. |
| Cast | Conversion explicite d’une valeur vers un autre type. |
| Classe | Définition d’un type décrivant notamment des champs et méthodes. |
| Classpath | Emplacements où Java recherche les classes à charger. |
| Collection | Structure qui rassemble des éléments, comme List ou Set. |
| Compilation | Transformation et vérification du code source avant son exécution. |
| Composition | Construction d’un objet à partir d’autres objets auxquels il peut déléguer des tâches. |
| Constructeur | Code d’initialisation appelé lors de la création d’une instance. |
| Encapsulation | Organisation qui protège l’état derrière des opérations respectant ses règles. |
| Enum | Type dont les valeurs appartiennent à un ensemble de constantes définies. |
| Exception | Signal d’un échec qui interrompt le chemin normal et peut être intercepté. |
| Générique | Type ou méthode paramétré par d’autres types, comme List&lt;String&gt;. |
| Héritage | Relation de spécialisation entre une classe et sa classe parente. |
| Immuable | Dont l’état observable ne change pas après construction. |
| Instance | Objet concret créé à partir d’une classe. |
| Interface | Contrat que plusieurs classes peuvent implémenter. |
| Invariant | Règle qui doit rester vraie pour un objet après ses opérations publiques. |
| JDK | Kit de développement contenant notamment le compilateur et les outils Java. |
| JVM | Machine virtuelle exécutant le bytecode Java. |
| Lambda | Écriture d’une petite opération adaptée à une interface fonctionnelle. |
| Méthode | Opération déclarée dans une classe ou une interface. |
| Null | Valeur de référence qui ne désigne aucun objet. |
| Package | Espace de noms regroupant des classes. |
| Paramètre | Variable locale qui reçoit une valeur lors de l’appel d’une méthode. |
| Polymorphisme | Possibilité d’appeler un même contrat avec des comportements adaptés aux objets réels. |
| Portée | Zone du code où un nom de variable est accessible. |
| Précondition | Exigence que l’appelant doit respecter avant une opération. |
| Record | Forme de classe destinée à représenter des données de valeur avec des méthodes générées. |
| Récursion | Résolution d’un problème par appel à une version plus petite du même problème. |
| Référence | Valeur permettant d’accéder à un objet. |
| Régression | Comportement auparavant correct qui devient défectueux après un changement. |
| Surcharge | Plusieurs méthodes de même nom avec des paramètres différents. |
| Redéfinition | Implémentation dans une sous-classe d’une méthode d’instance héritée. |
| Stream | Description d’un traitement séquentiel de données avec opérations intermédiaires et terminales. |
| Test | Vérification exécutable d’un comportement attendu. |
| UTF-8 | Encodage de texte permettant notamment de conserver les accents. |
